# OLV75 Configurator

A macOS desktop application for configuring and customizing the OLV75 custom keyboard.

OLV75 Configurator is being developed to provide a user-friendly interface for configuring keyboard behavior, managing key mappings, and accessing supported customization features without requiring users to edit firmware source code for every change.

## Development Status

**In development.** The application and its configuration workflows are still being built and validated. Feature availability depends on the application version and connected keyboard hardware. Consult the latest release notes and documentation for the functionality available in each version.

## Project Goals

OLV75 Configurator aims to:

1. Make keyboard customization accessible through a graphical interface.
2. Reduce the need for manual firmware changes during everyday configuration.
3. Provide consistent key mapping and layer management.
4. Develop a practical macro configuration experience.
5. Deliver a maintainable application with a polished user experience.

## Planned Features

- **Key mapping** — Customize key assignments.
- **Function layers** — Configure secondary key functions and Fn-layer behavior.
- **macOS support** — Account for macOS-specific keyboard behavior and shortcuts.
- **Backlight controls** — Access supported keyboard lighting settings.
- **Macro configuration** — Develop configurable keyboard macros and playback behavior.
- **Connection modes** — Support configuration workflows for the keyboard's connection modes.
- **User experience** — Improve configuration workflows, shortcuts, feedback, and usability.

These areas describe the project's direction; they do not imply that every feature is available in the current application version.

## Platform

- **Target platform:** macOS
- **Target device:** OLV75 custom keyboard
- **Application type:** Desktop configurator
